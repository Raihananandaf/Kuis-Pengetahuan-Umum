📘 Quiz Game – Pengetahuan Umum

Proyek ini adalah aplikasi Kuis Interaktif simple berbasis web yang dibuat dengan HTML, CSS, dan JavaScript.
Pengguna bisa menguji pengetahuan umum mereka melalui soal pilihan ganda, melihat skor akhir, serta mengulang kuis.

🚀 Fitur

✅ Halaman Start Screen dengan tombol mulai
✅ Soal pilihan ganda dengan tampilan interaktif
✅ Progress bar untuk menunjukkan perkembangan kuis
✅ Penilaian otomatis (10 poin per jawaban benar)
✅ Halaman hasil akhir dengan pesan motivasi sesuai skor
✅ Tombol Restart dan Quit

📂 Struktur Proyek

📦 quiz-game
 ┣ 📜 index.html      # Struktur utama halaman
 ┣ 📜 style.css       # Desain & styling
 ┗ 📜 script.js       # Logika kuis (soal, skor, interaksi)

## ⚡ Cara Menjalankan

1. Clone repositori ini:
   ```
   git clone https://github.com/username/quiz-game.git


2. Masuk ke folder proyek:
  ```
  cd quiz-game
  ```

Buka index.html di browser (klik dua kali atau drag ke browser).
✅ Tidak memerlukan server tambahan, langsung jalan di browser.

.

🎮 Cara Bermain

1. Klik tombol "Mulai Kuis" di halaman awal.
2. Pilih salah satu jawaban dari setiap pertanyaan.
3. Lihat skor langsung saat menjawab.
4. Setelah selesai, skor akhir dan pesan motivasi akan ditampilkan.
5. Gunakan tombol Restart untuk mengulang atau Quit untuk kembali ke halaman awal.


🛠️ Teknologi yang Digunakan

- **HTML5** → Struktur halaman
- **CSS3** → Styling dan responsif
- **JavaScript (Vanilla JS)** → Logika kuis & interaksi
